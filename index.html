// How I Think

My product operating system

01

Start with the problem

I don't start with features. I start with the user problem underneath them.

02

Talk to users

Assumptions are cheap. Evidence from real users is not.

03

Define success

Every feature needs a number attached before it ships.

04

Prioritize

Not everything valuable needs to be built right now.

05

Ship

A shipped experiment teaches more than a perfect idea sitting in Figma.

06

Iterate

Build, measure, learn, repeat — and let the data override my first guess.
